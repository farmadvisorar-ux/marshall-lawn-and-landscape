## 🚀 Instant Free Deployment on GitHub Pages

1. Create a new repository on [GitHub](https://github.com/new) named `marshall-lawn-and-landscape`.
2. Upload all files from this folder.
3. Go to **Settings** -> **Pages**.
4. Under **Source**, select `Deploy from a branch` -> `main` -> `/ (root)` -> Click **Save**.
5. Your site is instantly live at `https://<your-username>.github.io/marshall-lawn-and-landscape/`.
6. (Optional) Add your custom domain `marshalllawnandlandscape.com` under **Custom Domain**.
